# Analysis scripts

These scripts make the analysis tables in the `ws_trideep` database (schema `medproc`). They run in a team box. They are not part of the pool tasks.

| Script | What it makes |
|---|---|
| `medcorp_export.sql` | CSV files of the e-tenders, bids and financial bids of 11 state medical corporations, from the `gepnic-*` projects in `scrape_hub`. Replace `OUT/` with a folder, run it with `psql -d scrape_hub -f`, then load the files into `medproc.medcorp_tenders_raw`, `medproc.medcorp_bids` and `medproc.medcorp_prices`. |
| `wayback_removed.py` | Rows of the WBMSC tender and notice lists in Wayback copies that are not in the current lists. Run `python3 -I analysis/wayback_removed.py PAGES_DIR OUT.csv`, then load the file into `medproc.wbmsc_removed_rows`. |

The organisation ids of the corporations come from the `gepnic-*-plan` projects. The script does not copy the names of officials ("Updated By" fields).
| `debarment.sql` | Rebuilds `medproc.awards_during_debarment`: awards (accepted bidder, status AOC) to a firm inside a blacklist period of any corporation (`medproc.blacklist_periods`: TNMSC, RMSC, GMSCL, KMSCL). Firm names match after removing legal words and non-alphanumerics. Product-level lists cover one product of the firm: the award can be for another product. |
| `hospital_link.py` | Links tenders to the government hospital they are for (ABDM facility registry, table `ws_om.public.abdm_hfr_india_hospitals_partial`). Resolves abbreviations (SSH, SD and SS, MCH), hospital initials (NRS, MJN) and place spellings (Burdwan = Bardhaman); splits tenders that name several hospitals. Confidence `exact` (name + type, or 2+ name words for a hospital with no type word), `town` (a super speciality unit in a town whose registry entry is the district or sub-divisional hospital) or `pincode` (the registry uses another name, e.g. Krishnagar DH = Nadia District Hospital, and the pincode has one hospital of that type). Hospitals the title names are linked too (the location is often only the district, or cut off): `pool` is then `title-state` or `title-pincode`. Facility input: `hfr_input.sql` (Om's partial HFR hospitals, government medical colleges of the fuller table, and Om's reviewed candidates for names missing from the registry). Output: `medproc.tender_hospital`. Drug rate contracts deliver to warehouses and are not linked. The spelling and abbreviation tables are also published as a stand-alone module for other projects: https://github.com/insightLegion/indian-place-spellings (`placefix.py`); add new pairs in both places. |
